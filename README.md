# Analizador de Comentarios en Python

Sirve para guardar comentarios de estudiantes, buscarlos, contar palabras y hacer un resumen usando tuplas y listas.

## Como ejecutarlo
Hay que tener instalado Python y correr este comando en la terminal:

```bash
python main.py

---------Opciones del menu----------

Registrar un comentario nuevo.

Ver todos los comentarios q se han guardado.

Buscar palabras dentro de los comentarios.

Ver cuantas palabras tiene cada comentario.

Contar cuantas veces se repite una palabra en especifico.

Generar un resumen con tupla (caracteres, palabras y conteo).

Salir del programa.
